THE LEGACY — сайт-визитка

1. Положите rich.png в эту же папку, рядом с index.html.
2. Положите файл музыки с точным именем "gnaw alex g.m4a" туда же.
3. Откройте index.html в браузере.

Музыка запускается после нажатия «Войти в мой мир»: современные браузеры обычно блокируют автоматическое воспроизведение звука без действия пользователя.
Если файлы уже лежат в другой папке, переместите их рядом с index.html или измените пути в index.html.
